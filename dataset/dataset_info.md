# Dataset Information

## Overview

This project analyzes data-related job postings to identify hiring trends, salary benchmarks, employment patterns across the global data job market.

## Dataset Details

| Attribute | Details |
|------------|------------|
| Dataset Name | Data Job Postings 2024 |
| Records Analyzed | ~479,000 Job Postings |
| Domain | Data Analytics & Technology Careers |
| Analysis Tool | Power BI |
| Scope | Global Data-Related Job Postings |

## Repository Note

The original dataset has not been included in this repository due to file size considerations and repository optimization practices.

This repository focuses on:

- Data cleaning and transformation approach
- Dashboard development process
- Business insights generated from the analysis
- Visualization design and storytelling
- Final report and dashboard screenshots

## Contents Available

- Power BI Dashboard Screenshots
- Project Documentation
